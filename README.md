SkillSwap is a full-stack web app that enables users to **exchange skills** with others. Whether you're a **developer**, **dancer**, **designer**, or **chef**, you can find someone to **learn from and teach to** — absolutely free.

---

## ✨ Features

- 🔐 User Authentication (JWT)
- 🧩 Multi-step profile onboarding
- 🔍 Search & filter users by name/skills
- 💬 Real-time messaging system
- 📋 Role-based dashboards
- 🤖 (Optional) AI Chatbot
- 📱 Fully responsive design

---

## 🛠️ Tech Stack

### Frontend:
- React.js + Tailwind CSS
- React Router
- Context API

### Backend:
- Node.js + Express.js
- MongoDB + Mongoose
- JWT Auth
- bcrypt for password hashing
